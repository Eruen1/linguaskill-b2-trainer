# Linguaskill Business B2 Trainer

A professional, offline-capable Progressive Web App (PWA) designed to prepare for the **Cambridge Linguaskill Business B2** exam. Built with a modular vanilla JavaScript architecture, Tailwind CSS, and integrated Gemini AI features.

## Features
- **Flashcards:** English-English definitions and business collocations with 3D flip effect and audio synthesis.
- **Exam Simulations:** Authentic tasks for Reading, Listening, Writing, and Speaking in exact exam format.
- **Live AI Generator:** On-demand generation of custom B2 practice tasks tailored per skill using the Google Gemini API.
- **AI Writing Grader:** Instant evaluation of emails and business reports against official Cambridge criteria.
- **Mobile Optimized:** Designed as a PWA to run seamlessly on Android devices (add to home screen).

## Getting Started (Local Development)
1. Open the project folder in **Visual Studio Code**.
2. Install the **Live Server** extension.
3. Right-click `index.html` and select **Open with Live Server**.
4. Open the app settings (⚙️ API Key) in the top right to paste your free Google AI Studio API key.
